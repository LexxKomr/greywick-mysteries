# Greywick Mysteries: Solitaire Detective

Browser solitaire-detective game (Phaser 3 + Vite + TypeScript). Early test build.

- Play: https://OWNER.github.io/greywick-mysteries/
- Local run: `npm install`, then `npm run dev` → http://127.0.0.1:5173
- Tests: `npm test`. Build: `npm run build`.

Every push to `main` is built and published to GitHub Pages automatically.
